🥚 Combine Eggs — Rank Up

Eggs hatch as the rank they are. Combine 3 eggs of the same rank into 1 egg one rank higher.
Lowest → highest: COMMON → UNCOMMON → RARE → EPIC → LEGENDARY → MYTHIC → UNIQUE ⭐ (highest)
👆 Tap 3 eggs of the same rank to select them.

🔮 Combine Pets — Rank Up

Pick 2 pets of the same kind (same name + same rank). They merge into ONE pet one rank higher — same name, boosted stats. Equipped pets must be unequipped first.
👆 Tap 2 same-kind pet cards to select them.
