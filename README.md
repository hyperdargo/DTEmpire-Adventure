# 🤖 HermesBot v2.0

**Multi-Tasking Discord Bot** by Ankit Gupta

## Features

| Category | Commands |
|----------|----------|
| 📋 General | `!help` `!ping` `!uptime` `!status` `!serverinfo` `!userinfo` `!avatar` `!latestnews` |
| 🎵 Music | `!play` `!pause` `!resume` `!skip` `!stop` `!queue` `!nowplaying` `!volume` `!loop` `!shuffle` |
| 🎮 Games | `!roll` `!coinflip` `!8ball` `!rps` `!trivia` `!guess` `!hack` |
| 🎫 Tickets | `!ticket` `!close` `!add` `!remove` |
| 🛡️ Auto-Mod | `!automod` `!automod toggle` `!automod badwords` `!automod caps` `!automod mentions` |
| 🔧 Utility | `!poll` `!say` `!purge` `!announce` `!remind` |
| ⚙️ Admin | `!upgrade` `!restart` `!logs` `!setwelcome` `!setleave` `!eval` |

## Security
- 🔒 Locked to home server only
- 🚫 No DMs allowed (bot never responds to DMs)
- 📡 All events logged to central channel
- 🔄 Self-upgrading via git

## Setup
1. Copy `.env.example` to `.env` and fill in your bot token
2. `pip install discord.py yt-dlp python-dotenv`
3. `python bot.py`
